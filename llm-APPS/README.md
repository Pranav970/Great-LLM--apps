# 🧲 AI Competitor Intelligence Agent Team

The **AI Competitor Intelligence Agent Team** is an advanced, AI-powered application that streamlines competitor analysis for businesses. Built using [Firecrawl](https://firecrawl.dev/) and the [Agno AI Agent Framework](https://github.com/agnodice/agno), this app extracts structured data from competitor websites and transforms it into actionable strategic insights.

---

## 🚀 Features

### 🔁 Multi-Agent System
- **Firecrawl Agent**: Crawls and summarizes competitor websites
- **Analysis Agent**: Generates in-depth competitive analysis reports
- **Comparison Agent**: Creates structured comparisons between competitors

### 🔍 Competitor Discovery
- Identifies similar companies using URL matching via **Exa AI**
- Discovers competitors based on business descriptions
- Automatically extracts relevant competitor URLs for analysis

### 📊 Comprehensive Analysis
Delivers detailed reports that highlight:
- Market gaps and growth opportunities
- Competitor weaknesses
- Recommended features
- Pricing strategies
- Actionable strategic suggestions

### 🎛 Interactive Analysis
- Input your **company website URL** or a **business description**
- Instantly receive competitor insights, comparison tables, and recommendations

---

## 📦 Requirements

Install the following Python libraries:
- `agno`
- `exa-py`
- `streamlit`
- `pandas`
- `firecrawl-py`

You will also need API keys for:
- [OpenAI](https://platform.openai.com/api-keys)
- Firecrawl (from the [Firecrawl website](https://firecrawl.dev))
- Exa (from the [Exa website](https://exa.ai))
